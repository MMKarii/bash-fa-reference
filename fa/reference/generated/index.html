    فهرست کامل Reference Guide¶

    این فهرست به‌صورت خودکار از داده مرجع canonical تولید می‌شود.

    builtin¶

    • alias — نام‌های مستعار پوسته را تعریف یا نمایش می‌دهد.
    • bg — Jobهای متوقف‌شده را در پس‌زمینه ادامه می‌دهد.
    • bind — تنظیمات و کلیدهای میانبر Readline را مدیریت می‌کند.
    • break — از یک یا چند حلقه دربرگیرنده خارج می‌شود.
    • builtin — یک builtin پوسته را مستقیماً اجرا می‌کند.
    • caller — اطلاعات پشته فراخوانی تابع‌های پوسته را نمایش می‌دهد.
    • cd — دایرکتوری کاری جاری را تغییر می‌دهد.
    • command — فرمان را با نادیده‌گرفتن تابع‌های هم‌نام اجرا می‌کند یا نحوه یافتن فرمان را نشان می‌دهد.
    • compgen — گزینه‌های ممکن برای تکمیل خودکار را تولید می‌کند.
    • complete — قواعد تکمیل خودکار قابل‌برنامه‌ریزی را تعریف می‌کند.
    • compopt — گزینه‌های تکمیل خودکار را تغییر می‌دهد.
    • continue — اجرای حلقه دربرگیرنده را از iteration بعدی ادامه می‌دهد.
    • declare — متغیرها را تعریف و ویژگی‌های آن‌ها را تنظیم می‌کند.
    • dirs — پشته دایرکتوری‌ها را نمایش یا مدیریت می‌کند.
    • disown — Jobها را از جدول Job پوسته حذف می‌کند یا رفتار SIGHUP آن‌ها را تغییر می‌دهد.
    • echo — آرگومان‌ها را در خروجی استاندارد می‌نویسد.
    • enable — builtinهای پوسته را فعال، غیرفعال یا بارگذاری می‌کند.
    • eval — آرگومان‌ها را ترکیب و نتیجه را به‌عنوان ورودی پوسته اجرا می‌کند.
    • exec — پردازه پوسته جاری را با یک فرمان جایگزین می‌کند یا redirectionها را اعمال می‌کند.
    • exit — پوسته را با وضعیت خروج اختیاری خاتمه می‌دهد.
    • export — متغیرها را برای انتقال به پردازه‌های فرزند export می‌کند.
    • false — همیشه وضعیت ناموفق برمی‌گرداند.
    • fc — فرمان‌های history را فهرست، ویرایش یا دوباره اجرا می‌کند.
    • fg — یک Job را به foreground منتقل می‌کند.
    • getopts — پارامترهای positional را به‌عنوان گزینه‌های خط فرمان تجزیه می‌کند.
    • hash — مسیر فرمان‌ها را cache، نمایش یا حذف می‌کند.
    • help — راهنمای builtinهای پوسته را نمایش می‌دهد.
    • history — فهرست history پوسته را نمایش یا مدیریت می‌کند.
    • jobs — وضعیت Jobها را نمایش می‌دهد یا jobspecها را جایگزین می‌کند.
    • kill — برای پردازه‌ها یا Jobها signal ارسال می‌کند.
    • let — عبارت‌های حسابی Bash را ارزیابی می‌کند.
    • local — متغیرهای محلی برای تابع پوسته ایجاد می‌کند.
    • logout — از login shell خارج می‌شود.
    • mapfile — خطوط ورودی را در یک آرایه indexed می‌خواند.
    • popd — ورودی‌هایی را از پشته دایرکتوری حذف می‌کند.
    • printf — داده را قالب‌بندی و چاپ می‌کند یا با -v در متغیر قرار می‌دهد.
    • pushd — ورودی جدید به پشته دایرکتوری اضافه می‌کند یا آن را می‌چرخاند.
    • pwd — دایرکتوری کاری جاری را چاپ می‌کند.
    • read — ورودی را می‌خواند و فیلدها را به متغیرهای پوسته اختصاص می‌دهد.
    • readarray — خطوط ورودی را در آرایه indexed می‌خواند و معادل mapfile است.
    • readonly — متغیرها یا تابع‌ها را readonly می‌کند.
    • return — از تابع یا فایل sourceشده با وضعیت اختیاری بازمی‌گردد.
    • set — گزینه‌های پوسته و پارامترهای positional را تنظیم می‌کند.
    • shift — پارامترهای positional را به چپ shift می‌دهد.
    • shopt — گزینه‌های مخصوص Bash را مشاهده یا تغییر می‌دهد.
    • source — فرمان‌های یک فایل را در محیط همان پوسته اجرا می‌کند.
    • suspend — اجرای پوسته جاری را متوقف می‌کند.
    • test — یک عبارت شرطی را ارزیابی و وضعیت truth آن را برمی‌گرداند.
    • times — زمان CPU کاربر و سیستم را نمایش می‌دهد.
    • trap — handlerهای signal و pseudo-signalهای Bash را تنظیم می‌کند.
    • true — همیشه وضعیت موفق برمی‌گرداند.
    • type — نشان می‌دهد نام فرمان‌ها چگونه resolve می‌شوند.
    • typeset — متغیرها و ویژگی‌های آن‌ها را تعریف می‌کند و در Bash هم‌معنی declare است.
    • ulimit — محدودیت منابع پردازه‌های پوسته را نمایش یا تغییر می‌دهد.
    • umask — ماسک مجوز ایجاد فایل را نمایش یا تنظیم می‌کند.
    • unalias — aliasهای پوسته را حذف می‌کند.
    • unset — متغیرها یا تابع‌ها را از محیط پوسته حذف می‌کند.
    • wait — برای پایان Jobها یا پردازه‌ها منتظر می‌ماند و وضعیت خروج را برمی‌گرداند.

    concept¶

    • arrays — آرایه‌های indexed چند مقدار را با index عددی نگهداری می‌کنند.
    • associative arrays — آرایه‌های associative مقدارها را با کلید رشته‌ای نگهداری می‌کنند.
    • conditionals — ساختارهای شرطی رفتار را بر اساس وضعیت فرمان یا expression انتخاب می‌کنند.
    • debugging — Debugging در Bash از trace، trap، بررسی status و تحلیل ایستا استفاده می‌کند.
    • defensive scripting — اسکریپت دفاعی expansionها را quote، ورودی را validate، خطاها را بررسی، privilege را کم و cleanup را قابل پیش‌بینی می‌کند.
    • environment — محیط پوسته مجموعه‌ای از name-valueهای exportشده است که پردازه‌های فرزند به ارث می‌برند.
    • exit status — فرمان‌ها موفقیت یا شکست را با مقدار عددی exit status گزارش می‌کنند.
    • functions — تابع‌های پوسته مجموعه فرمان‌ها را با یک نام قابل استفاده مجدد در همان پوسته گروه‌بندی می‌کنند.
    • command grouping — Brace فرمان‌ها را در همان پوسته و پرانتز در subshell گروه‌بندی می‌کند.
    • here documents — Here document ورودی چندخطی را تا رسیدن به delimiter فراهم می‌کند.
    • here strings — Here string یک word گسترش‌یافته را به‌عنوان ورودی استاندارد ارائه می‌کند.
    • job control — Job control pipelineهای foreground و background را در shell تعاملی مدیریت می‌کند.
    • loops — ساختارهای loop یک فهرست فرمان را بر اساس شرط یا مجموعه آیتم‌ها تکرار می‌کنند.
    • pipelines — Pipeline خروجی یک فرمان را به ورودی فرمان بعدی متصل و یک وضعیت نهایی تولید می‌کند.
    • portability — اسکریپت portable رفتار POSIX را از قابلیت‌های مخصوص Bash و تفاوت نسخه‌ها جدا می‌کند.
    • redirections — Redirection مشخص می‌کند فرمان‌ها ورودی را از کجا بخوانند و خروجی را کجا بنویسند.
    • shell options — builtin set گزینه‌های اجرایی shell را فعال یا غیرفعال می‌کند.
    • shopt options — builtin shopt رفتارهای اختیاری مخصوص Bash را کنترل می‌کند.
    • signals — Signalها رخدادهای asynchronous را به پردازه‌ها اطلاع می‌دهند و با trap قابل مدیریت‌اند.
    • startup files — Bash بر اساس حالت login، interactive و نحوه اجرا فایل‌های startup متفاوتی می‌خواند.
    • subshells — پرانتز یک فهرست فرمان را در محیط subshell اجرا می‌کند.
    • traps — Trap کد پوسته را به signalها و pseudo-signalهایی مانند EXIT و DEBUG متصل می‌کند.

    example¶

    • pipeline example — نمونه pipeline مقاوم quoting را حفظ می‌کند و در صورت نیاز statusهای pipeline را بررسی می‌کند.
    • trap example — یک cleanup trap پاک‌سازی منابع را هنگام خروج اسکریپت به‌صورت متمرکز و قابل پیش‌بینی انجام می‌دهد.

    expansion¶

    • arithmetic expansion — Arithmetic expansion یک عبارت حسابی را ارزیابی و مقدار آن را جایگزین می‌کند.
    • brace expansion — Brace expansion مجموعه‌ای از رشته‌ها را از list یا sequence داخل brace تولید می‌کند.
    • command substitution — Command substitution یک ساختار را با خروجی استاندارد یک فرمان جایگزین می‌کند.
    • parameter expansion — Parameter expansion مقدار پارامترهای پوسته را می‌خواند و تبدیل می‌کند.
    • pathname expansion — Pathname expansion الگوهای glob را با مسیرهای مطابق جایگزین می‌کند.
    • process substitution — Process substitution ورودی یا خروجی فرمان را از طریق مسیری شبیه فایل در دسترس می‌گذارد.

    option¶

    • allexport — متغیرهای ایجاد یا تغییرکرده را به‌صورت خودکار برای export علامت می‌زند.
    • braceexpand — Brace expansion مانند {a,b} و {1..5} را فعال می‌کند.
    • emacs — ویرایش خط فرمان Readline به سبک Emacs را فعال می‌کند.
    • errexit — errexit از پوسته می‌خواهد پس از برخی failureهای مدیریت‌نشده خارج شود و استثناهای آن به context وابسته‌اند.
    • errtrace — باعث می‌شود trap مربوط به ERR در functionها، command substitutionها و subshellها به ارث برسد.
    • functrace — باعث می‌شود trapهای DEBUG و RETURN در functionها و command substitutionها به ارث برسند.
    • hashall — مسیر commandها را هنگام lookup در hash table نگه می‌دارد.
    • histexpand — History expansion را با نویسه مخصوص history فعال می‌کند.
    • history — ثبت و استفاده از command history را فعال می‌کند.
    • ignoreeof — از خروج shell تعاملی با یک EOF جلوگیری می‌کند.
    • interactive-comments — اجازه می‌دهد # در shell تعاملی آغازگر comment باشد.
    • keyword — assignmentهای موجود در آرگومان‌های command را در محیط همان command اعمال می‌کند.
    • monitor — Job control را فعال می‌کند.
    • noclobber — به‌صورت پیش‌فرض از overwrite شدن فایل‌های موجود با redirection نوع > جلوگیری می‌کند.
    • noexec — commandها را می‌خواند اما اجرا نمی‌کند و برای بررسی syntax مفید است.
    • noglob — Pathname expansion یا globbing را غیرفعال می‌کند.
    • notify — پایان jobهای پس‌زمینه را سریع‌تر گزارش می‌کند.
    • nounset — nounset استفاده از متغیر unset را در contextهای مربوط خطا در نظر می‌گیرد.
    • onecmd — پس از خواندن و اجرای یک command خارج می‌شود.
    • physical — برای رفتار cd/pwd از مسیر فیزیکی به‌جای مسیر منطقی symlinkها استفاده می‌کند.
    • pipefail — pipefail باعث می‌شود status pipeline خطای راست‌ترین فرمان ناموفق را منعکس کند، نه فقط فرمان آخر را.
    • posix — رفتار Bash را به الزامات POSIX shell نزدیک‌تر می‌کند.
    • privileged — Privileged mode را فعال می‌کند و بر startup fileها، functionهای محیطی و IDهای مؤثر اثر می‌گذارد.
    • verbose — خطوط ورودی shell را هنگام خوانده‌شدن چاپ می‌کند.
    • vi — ویرایش خط فرمان Readline به سبک vi را فعال می‌کند.
    • xtrace — xtrace فرمان‌های expandشده را پیش از اجرا برای trace و debugging چاپ می‌کند.

    shopt¶

    • array_expand_once — ارزیابی تکراری subscriptهای array را در برخی contextها محدود می‌کند.
    • assoc_expand_once — نام قدیمی و deprecated برای array_expand_once است.
    • autocd — در shell تعاملی نام directory را مثل cd ضمنی در نظر می‌گیرد.
    • bash_source_fullpath — مسیرهای کامل را در عناصر BASH_SOURCE ذخیره می‌کند.
    • cdable_vars — به cd اجازه می‌دهد آرگومان غیر-directory را نام متغیری حاوی مسیر در نظر بگیرد.
    • cdspell — خطاهای کوچک تایپی مسیرهای cd را اصلاح می‌کند.
    • checkhash — پیش از اجرای commandهای hash‌شده وجود مسیر ذخیره‌شده را بررسی می‌کند.
    • checkjobs — پیش از خروج shell تعاملی jobهای در حال اجرا یا متوقف را بررسی و گزارش می‌کند.
    • checkwinsize — در صورت تغییر اندازه terminal، LINES و COLUMNS را به‌روزرسانی می‌کند.
    • cmdhist — commandهای چندخطی را تا حد ممکن به‌صورت یک history entry ذخیره می‌کند.
    • direxpand — هنگام completion نام directory را expand کرده و متن را با مسیر expandشده جایگزین می‌کند.
    • dirspell — هنگام completion برای نام directory اصلاح تایپی انجام می‌دهد.
    • dotglob — فایل‌هایی که با . شروع می‌شوند را در نتیجه globbing وارد می‌کند.
    • execfail — اگر exec نتواند command را اجرا کند، shell غیرتعاملی فوراً خارج نمی‌شود.
    • expand_aliases — Alias expansion را در shellهای غیرتعاملی نیز فعال می‌کند.
    • extdebug — رفتار debugging پیشرفته برای functionها، trapها و متغیرهای call stack را فعال می‌کند.
    • extglob — Patternهای توسعه‌یافته مانند ?()، *()، +()، @() و !() را فعال می‌کند.
    • failglob — اگر glob هیچ match نداشته باشد خطای expansion ایجاد می‌کند.
    • force_fignore — باعث می‌شود suffixهای FIGNORE حتی در حالت تنها match بودن نیز در completion حذف شوند.
    • globasciiranges — برای rangeهای bracket در pathname matching از ترتیب ASCII استفاده می‌کند.
    • globskipdots — از match شدن . و .. در pathname expansion جلوگیری می‌کند.
    • globstar — globstar باعث می‌شود ** در pathname expansion به‌صورت recursive در سطح‌های دایرکتوری match شود.
    • gnu_errfmt — پیام‌های خطای shell را در قالب GNU مانند file:line قالب‌بندی می‌کند.
    • histappend — هنگام خروج shell، history را به فایل اضافه می‌کند و overwrite نمی‌کند.
    • histreedit — در صورت شکست history expansion امکان ویرایش مجدد command را می‌دهد.
    • histverify — متن history-expanded را ابتدا وارد editing buffer می‌کند و مستقیم اجرا نمی‌کند.
    • hostcomplete — در context مناسب hostname completion انجام می‌دهد.
    • huponexit — هنگام خروج login shell تعاملی به jobها SIGHUP می‌فرستد.
    • inherit_errexit — باعث می‌شود command substitution گزینه errexit را به ارث ببرد.
    • interactive_comments — Commentهای # را در shell تعاملی فعال می‌کند.
    • lastpipe — وقتی job control غیرفعال است اجازه می‌دهد آخرین command pipeline در shell جاری اجرا شود.
    • lithist — در history چندخطی newlineهای واقعی را حفظ می‌کند.
    • localvar_inherit — متغیر local مقدار و attributeهای متغیر هم‌نام scope بیرونی را به ارث می‌برد.
    • localvar_unset — اطلاعات scope متغیر local را پس از unset تا پایان function حفظ می‌کند.
    • mailwarn — اگر فایل mail از زمان آخرین بررسی دسترسی خورده باشد هشدار می‌دهد.
    • no_empty_cmd_completion — در completion خط command خالی، PATH را جست‌وجو نمی‌کند.
    • nocaseglob — Pathname expansion را نسبت به بزرگی و کوچکی حروف غیرحساس می‌کند.
    • nocasematch — Pattern matching در case و [[ ]] را نسبت به بزرگی و کوچکی حروف غیرحساس می‌کند.
    • noexpand_translation — پس از ترجمه locale، رشته‌های $"..." را دوباره expand نمی‌کند.
    • nullglob — nullglob الگوی glob بدون match را حذف می‌کند به‌جای اینکه خود الگو literal باقی بماند.
    • patsub_replacement — در replacement مربوط به parameter substitution، & بدون quote را بخش match‌شده می‌داند.
    • progcomp — Programmable completion را فعال می‌کند.
    • progcomp_alias — اگر programmable completion spec پیدا نشود alias expansion را امتحان می‌کند.
    • promptvars — روی promptها expansionهای shell را انجام می‌دهد.
    • restricted_shell — نشان می‌دهد shell در restricted mode اجرا می‌شود.
    • shift_verbose — اگر تعداد shift از positional parameterها بیشتر باشد خطا گزارش می‌کند.
    • sourcepath — برای یافتن فایل source و . در صورت نیاز از PATH استفاده می‌کند.
    • varredir_close — file descriptorهای ساخته‌شده با redirection نوع {varname} را خودکار می‌بندد.
    • xpg_echo — باعث می‌شود echo به‌صورت پیش‌فرض backslash escapeها را تفسیر کند.

    syntax¶

    • arithmetic-command — یک arithmetic expression را به‌عنوان shell command ارزیابی می‌کند.
    • case — با match کردن word در برابر patternهای shell یک command list را انتخاب می‌کند.
    • conditional-command — Conditional expressionهای Bash را بدون word splitting معمول ارزیابی می‌کند.
    • for — روی wordها iteration انجام می‌دهد و هر مقدار را به متغیر می‌دهد.
    • function — یک shell function تعریف می‌کند.
    • group-command — یک command list را در محیط shell فعلی اجرا می‌کند.
    • if — بر اساس exit status یک یا چند command list را شرطی اجرا می‌کند.
    • quoting — Quoting تعیین می‌کند کدام نویسه‌ها و expansionها معنای literal خود را حفظ کنند.
    • select — یک منوی شماره‌دار تعاملی نمایش می‌دهد و word انتخاب‌شده را assign می‌کند.
    • subshell — یک command list را در subshell اجرا می‌کند.
    • until — تا زمانی که test موفق نشده باشد commandها را تکرار می‌کند.
    • while — تا زمانی که test موفق باشد commandها را تکرار می‌کند.

    variable¶

    • BASH — مسیر executable فعلی Bash را نشان می‌دهد.
    • BASHOPTS — فهرست readonly و جداشده با colon از shopt optionهای فعال است.
    • BASHPID — PID پردازه فعلی Bash است.
    • BASH_ALIASES — Associative array مربوط به aliasهای فعلی shell است.
    • BASH_ARGC — Array call stack شامل تعداد آرگومان frameهای فعال است.
    • BASH_ARGV — Array مربوط به آرگومان‌های frameهای فعال call stack است.
    • BASH_ARGV0 — متغیری برای خواندن یا تغییر مقداری است که Bash به‌عنوان $0 ارائه می‌کند.
    • BASH_CMDS — Associative array مربوط به command hash table داخلی Bash است.
    • BASH_COMMAND — Command فعلی یا commandی که در آستانه اجراست را نشان می‌دهد.
    • BASH_COMPAT — سطح compatibility مربوط به نسخه‌های قدیمی‌تر Bash را انتخاب می‌کند.
    • BASH_ENV — startup file مربوط به Bash غیرتعاملی در شرایط مربوط است.
    • BASH_LINENO — Array شماره‌خط‌های source متناظر با call stack است.
    • BASH_REMATCH — نتیجه آخرین regex match و groupهای captureشده را نگه می‌دارد.
    • BASH_SOURCE — BASH_SOURCE آرایه‌ای از نام فایل‌های source متناظر با call stack جاری است.
    • BASH_SUBSHELL — سطح nesting مربوط به subshell در context فعلی است.
    • BASH_VERSINFO — Array readonly شامل اجزای نسخه Bash در حال اجرا است.
    • BASH_VERSION — رشته نسخه Bash در حال اجرا است.
    • DIRSTACK — Array مربوط به directory stack فعلی است.
    • EPOCHREALTIME — زمان فعلی Unix epoch را با بخش اعشاری ارائه می‌کند.
    • EPOCHSECONDS — زمان فعلی Unix epoch را برحسب ثانیه ارائه می‌کند.
    • FUNCNAME — Array نام functionهای call stack فعلی است.
    • HISTCMD — شماره history مربوط به command فعلی است.
    • HOSTNAME — نام host فعلی را نشان می‌دهد.
    • LINENO — شماره خط فعلی در script یا shell function است.
    • MACHTYPE — توصیف canonical به سبک GNU از platform است.
    • OLDPWD — دایرکتوری کاری قبلی که توسط cd تنظیم شده است.
    • OPTARG — مقدار آرگومان option فعلی که getopts پردازش می‌کند.
    • OPTIND — index آرگومان بعدی که getopts باید پردازش کند.
    • OSTYPE — رشته توصیف سیستم‌عاملی است که Bash برای آن build شده است.
    • PIPESTATUS — PIPESTATUS آرایه‌ای از exit statusهای آخرین pipeline foreground اجراشده است.
    • PPID — PID پردازه والد shell است.
    • PROMPT_COMMAND — Command یا arrayی است که Bash پیش از نمایش prompt اصلی اجرا می‌کند.
    • PWD — دایرکتوری کاری فعلی shell است.
    • RANDOM — در هر expansion یک عدد شبه‌تصادفی تولید می‌کند.
    • REPLY — متغیر مقصد پیش‌فرض read است.
    • SECONDS — ثانیه‌های سپری‌شده از شروع shell یا آخرین assignment است.
    • SHELLOPTS — فهرست readonly و جداشده با colon از optionهای فعال set -o است.
    • SHLVL — سطح nesting shell است.
    • SRANDOM — یک مقدار تصادفی ۳۲ بیتی ارائه می‌کند.
