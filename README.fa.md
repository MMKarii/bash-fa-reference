# مرجع حرفه‌ای Bash — نسخه فارسی

![Bash Professional Reference](docs/fa/assets/brand-banner.webp)

این مخزن نسخه حرفه‌ای و ساختارمند مجموعه مقالات Bash است: مبانی پوسته و خط فرمان، مدیریت فایل و پردازه، Pipe و Redirection، پردازش متن، اسکریپت‌نویسی، خودکارسازی، مدیریت سیستم، DevOps، امنیت دفاعی، Debugging و مقایسه Bash با پوسته‌های دیگر.

**شروع مطالعه:** [docs/fa/index.md](docs/fa/index.md)

محتوای اصلی از فایل‌های Word ارائه‌شده استخراج و ادغام شده است؛ تکرارها و متن‌های Placeholder حذف شده‌اند و نکات فنی حساس به رفتار Bash با مستند رسمی GNU تطبیق داده شده‌اند.
