# Bashref News

## 2.1.0

The 2.1 line expands Bashref from a focused 97-record reference into a substantially broader 214-record bilingual corpus. It adds broad shell-option and shopt coverage, major Bash special variables, compound-command syntax entries, and the new `bashref stats` and `bashref doctor` commands.

Project documentation now includes dedicated installation and hacking guides in addition to contribution, security, release, Reference Guide, and Professional Guide documentation.

## 2.0.0

First integrated Bashref software release. Added the offline CLI, bilingual structured reference, generated Reference Guide/man pages, shell completions, wheel/sdist, DEB/RPM packaging, Homebrew formula generation, release artifacts, checksums, and verified versioned website publication.

## 1.0.0

Initial professional bilingual Persian/English documentation release with 14 mirrored handbook chapters, learning path, cheat sheet, glossary, strict QA, and GitHub Pages deployment.
