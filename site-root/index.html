Bashref: master Bash from the terminal to the reference manual

Bashref is a free, open-source, bilingual Bash reference project for command-line work, scripting, automation, system administration, DevOps, debugging, portability, and defensive security. It combines an offline CLI, generated man pages, installable packages, a structured Reference Guide, and a fourteen-chapter Professional Guide.

The reference is available in English and فارسی. Core CLI lookup and search work offline after installation. Bash behavior is cross-checked primarily against the GNU Bash Reference Manual.

$ bashref search quoting $ bashref builtin printf $ bashref option pipefail $ bashref shopt extglob $ bashref variable BASH_VERSION $ bashref doctor

Bashref is...

  • Comprehensive: 214 bilingual records covering builtins, syntax, expansions, shell options, shopt, variables, concepts, and examples. 214-record corpus
  • Offline: reference lookup, search, JSON output, diagnostics, and shell completions do not require network access.
  • Portable: release artifacts include a Python wheel, source distribution, Debian package, RPM package, Homebrew formula, portable archive, man pages, and completions.
  • Well documented: the generated Reference Guide is complemented by the Professional Guide, installation documentation, contributor guidance, security policy, and system man pages.
  • Bilingual: Persian and English records share stable IDs so equivalent reference topics stay paired across languages.
  • Verifiable: releases include SHA-256 checksums and are built and tested by the protected CI pipeline.
