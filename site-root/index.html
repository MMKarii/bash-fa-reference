Bashref: Master the shell

Bashref is a free and open source bilingual Bash reference for command-line work, scripting, automation, system administration, DevOps, debugging, portability, and defensive security. It combines an offline CLI, generated man pages, installable packages, a structured Reference Guide, and a fourteen-chapter Professional Guide.

The reference is available in English and فارسی. Core lookup and search work offline after installation. Bash-specific behavior is cross-checked primarily against the GNU Bash Reference Manual.

Bashref is ...

  • Comprehensive: 214 bilingual records covering builtins, syntax, expansions, shell options, shopt, variables, concepts, and examples.
  • Powerful: direct lookup, full-text search, machine-readable JSON, diagnostics, generated man pages, and versioned documentation are available from one project.
  • Portable: wheel, source distribution, Debian package, RPM package, Homebrew formula, portable archive, man pages, and completions are published as release artifacts.
  • Easy: start with commands such as bashref search quoting or bashref builtin printf.
  • Free: software code is MIT-licensed and documentation is published under CC BY 4.0.
  • Well Documented: the generated Reference Guide is complemented by a Professional Guide, install documentation, contributor documentation, and man pages.
  • Bilingual: English and Persian records share stable IDs and matching reference topics.
$ bashref search quoting
$ bashref builtin printf
$ bashref option pipefail
$ bashref shopt extglob
$ bashref variable BASH_VERSION
$ bashref doctor

Communication

Bug reports, documentation corrections, feature requests, and contribution proposals are handled through the GitHub issue tracker. Development history, pull requests, release artifacts, and source code are available in the public repository. Security-sensitive reports should use the repository's security reporting channel.
