# Support

## User questions and bug reports

Use GitHub Issues for reproducible bugs, documentation errors, packaging problems, and feature requests.

Include:

- `bashref --version`
- `bashref --format json doctor`
- operating system and installation method
- exact command
- expected result
- observed result

Remove credentials, tokens, private hostnames, and sensitive infrastructure details before posting.

## Security reports

Do not open a public issue for a vulnerability that could expose credentials, cause destructive behavior, or compromise users. Follow [SECURITY.md](SECURITY.md) and use GitHub private security reporting when available.

## Supported release lines

- **2.1.x:** current feature and bug-fix line after publication.
- **2.0.x:** previous stable line; critical correctness/security fixes only while 2.1 is current.
- **1.0.x:** historical documentation snapshot; no software runtime support.

The live site documents the current line. Versioned snapshots remain available for historical releases.
