    cd¶

    Change the current working directory.

    Synopsis¶

    cd [-L|[-P [-e]] [-@]] [dir]

    Description¶

    Change the current working directory. This entry documents the Bash builtin and its shell-state effects.

    Portability¶

    • Options beyond POSIX may be Bash-specific.
