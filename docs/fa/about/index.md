# درباره Bashref

Bashref یک پروژه مرجع دوزبانه فارسی/انگلیسی برای Bash است که سه لایه اصلی دارد:

1. **Bashref CLI** برای جست‌وجو و مراجعه آفلاین در ترمینال.
2. **Reference Guide** برای builtinها، syntax، expansionها، optionها، variableها و conceptهای Bash.
3. **Professional Guide** برای یادگیری ساختاریافته، مدیریت سیستم، اتوماسیون، DevOps، Debugging و اسکریپت‌نویسی دفاعی.

برای رفتارهای ویژه Bash، مستند رسمی GNU Bash مرجع اصلی است. Bashref جایگزین GNU Manual نیست و مثال‌های مستندات را اجرا نمی‌کند.

کد نرم‌افزار تحت MIT و متن مستندات/مرجع تحت CC BY 4.0 منتشر می‌شود.
