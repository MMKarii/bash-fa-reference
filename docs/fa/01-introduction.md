# ۱. مبانی Bash و مدل Shell

Bash مخفف **Bourne Again Shell** است؛ هم یک پوسته تعاملی و هم زبان اسکریپت‌نویسی برای سیستم‌های شبه‌یونیکس. Bash دستور متنی را دریافت می‌کند، Expansionها را انجام می‌دهد، Redirection و Pipeline را می‌سازد و در نهایت Builtin یا برنامه خارجی را اجرا می‌کند.

مجموعه منابع اولیه روی سه نقش تأکید دارند: **تعامل روزمره با لینوکس، خودکارسازی و مدیریت سیستم**. همین سه محور ساختار این مرجع را شکل می‌دهند.

## Shell، Terminal و Kernel

- Terminal محیطی است که ورودی/خروجی متنی را نمایش می‌دهد.
- Shell فرمان را تفسیر می‌کند.
- Kernel منابع سیستم، پردازه‌ها، فایل‌ها و دستگاه‌ها را مدیریت می‌کند.
- بسیاری از دستورهایی که در Bash اجرا می‌شوند خود Bash نیستند؛ برنامه‌های جداگانه‌ای مثل `grep`, `find`, `tar`, `ssh` و `rsync` هستند.

## تاریخچه کوتاه

Bash در پروژه GNU توسعه یافت و در بسیاری از محیط‌های Linux به پوسته‌ای بسیار رایج تبدیل شد. روی macOS نیز قابل نصب است، هرچند پوسته پیش‌فرض نسخه‌های جدید macOS، Zsh است.

## تشخیص نسخه

```bash
bash --version
printf '%s\n' "$BASH_VERSION"
```

این مرجع رفتارهای Bash را با مستند نسخه 5.3 GNU تطبیق می‌دهد، اما همیشه نسخه واقعی محیط خود را بررسی کنید.
