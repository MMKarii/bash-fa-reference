# سلب مسئولیت و محدوده استفاده

این مستند برای آموزش Bash، مدیریت سیستم، DevOps، خودکارسازی و امنیت دفاعی تهیه شده است.

فرمان‌هایی که فایل، مجوز، مالکیت، سرویس، شبکه یا داده را تغییر می‌دهند ممکن است اثر دائمی داشته باشند. قبل از اجرای آن‌ها روی محیط Production، نسخه پشتیبان، Scope، سطح دسترسی و مسیر rollback را بررسی کنید.

نمونه‌های امنیتی فقط برای سیستم‌های تحت مالکیت/مدیریت شما یا محیط‌های آزمایشگاهی هستند. این مخزن برای دورزدن کنترل امنیتی یا هدف‌گیری سامانه‌های ثالث طراحی نشده است.
