# منابع

## منابع مرجع فنی

- [GNU Bash Reference Manual](https://www.gnu.org/software/bash/manual/bash.html) — مرجع اصلی semantics و امکانات Bash.
- [GNU Bash project](https://www.gnu.org/software/bash/) — صفحه رسمی پروژه.
- [ShellCheck](https://github.com/koalaman/shellcheck) — تحلیل ایستا و تشخیص خطاهای رایج Shell script.
- [ShellCheck website](https://www.shellcheck.net/) — اجرای آنلاین تحلیل.
- [POSIX Shell Command Language](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html) — مرجع portability برای Shell استاندارد.

## منابع مبنای پروژه

ساختار و مثال‌های این مرجع از مجموعه فایل‌های Word ارائه‌شده توسط صاحب مخزن ادغام شده‌اند؛ از جمله نسخه کامل Bash، نسخه دانشگاهی ۲۰۲۵، نسخه بازبینی‌شده و فایل‌های امنیتی. تکرارهای مصنوعی و Placeholderها وارد نسخه نهایی نشده‌اند.

برای رفتار دقیق Bash، منبع رسمی GNU بر نسخه‌های ثانویه اولویت دارد.
