# دانلود

فایل‌های انتشار Bashref 2.1.0 در GitHub Releases منتشر می‌شوند.

خروجی‌های اصلی:

- `bashref-2.1.0-py3-none-any.whl`
- `bashref-2.1.0.tar.gz`
- `bashref_2.1.0_all.deb`
- `bashref-2.1.0-1.noarch.rpm`
- `bashref-2.1.0-portable.tar.gz`
- `bashref-2.1.0-manpages.tar.gz`
- `bashref-2.1.0-completions.tar.gz`
- `SHA256SUMS`

## بررسی صحت فایل‌ها

پس از قرار دادن فایل‌ها و `SHA256SUMS` در یک پوشه:

```bash
sha256sum -c SHA256SUMS
```

برای دانلود از صفحه [GitHub Releases](https://github.com/MMKarii/bash-fa-reference/releases) استفاده کنید.
