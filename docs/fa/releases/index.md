# انتشارها

## Bashref 2.1.0

Bashref 2.1.0 مجموعه مرجع ساختاریافته دوزبانه را به ۲۱۴ رکورد گسترش می‌دهد و پوشش گسترده‌تری برای shell optionها، `shopt`، متغیرهای مهم Bash و syntax مربوط به compound commandها اضافه می‌کند.

همچنین شامل این موارد است:

- `bashref stats` برای مشاهده پوشش مجموعه مرجع
- `bashref doctor` برای diagnostics آفلاین runtime
- فایل‌های مستقل `INSTALL.md`، `HACKING.md`، `AUTHORS.md` و `NEWS.md`
- snapshotهای مستندات که از tag دقیق ساخته می‌شوند
- verification انتشار وابسته به نسخه

## Bashref 2.0.0

اولین انتشار یکپارچه نرم‌افزار شامل CLI، مجموعه ۹۷ رکوردی، Reference Guide و man page تولیدشده، completionها، wheel/sdist، بسته‌های Debian/RPM، Homebrew formula، آرشیوهای portable و checksumها بود.

انتشار مستندات v1.0.0 به‌عنوان snapshot تاریخی بدون تغییر حفظ می‌شود.

صفحه [انتشارهای پروژه](https://github.com/MMKarii/bash-fa-reference/releases) را ببینید.
