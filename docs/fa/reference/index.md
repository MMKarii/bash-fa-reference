# Reference Guide مرجع Bash

**Reference Guide** بخش مراجعه سریع Bashref است. این بخش از همان داده canonical تولید می‌شود که CLI و man pageها استفاده می‌کنند؛ در نتیجه syntax، خلاصه‌ها و source linkها هم‌راستا می‌مانند.

برای مراجعه دقیق به builtinها، optionهای پوسته، expansionها، variableها، syntax و conceptهای اصلی Bash از این بخش استفاده کنید.

- [فهرست کامل تولیدشده](generated/)
- مراجعه در CLI: `bashref --lang fa builtin printf`
- جست‌وجو: `bashref --lang fa search quoting`
- خروجی machine-readable: `bashref --lang fa --format json builtin read`

برای آموزش مرحله‌به‌مرحله و سناریوهای عملی از [Professional Guide](../book/) استفاده کنید.
