# پرسش‌های متداول

## آیا Bashref مثال‌ها را اجرا می‌کند؟

خیر. رکوردهای مرجع فقط داده هستند و lookup/search عادی هیچ مثال shell را eval یا اجرا نمی‌کند.

## آیا اینترنت لازم است؟

برای lookup، search، list، diagnostics، انتخاب زبان و JSON خیر. فقط قابلیت صریح `bashref docs --open` سایت را باز می‌کند.

## آیا Bash باید نصب باشد؟

برای استفاده از مرورگر مرجع خیر. فقط وقتی خودتان قصد اجرای فرمان‌های Bash را دارید به Bash نیاز است.

## زبان پیش‌فرض چگونه انتخاب می‌شود؟

`--lang` صریح اولویت اول است، سپس preference ذخیره‌شده، سپس locale فارسی و در نهایت English.

## تفاوت Reference Guide و Professional Guide چیست؟

Reference Guide برای مراجعه دقیق و از داده ساختاریافته تولید می‌شود. Professional Guide راهنمای طولانی‌تر آموزشی و عملیاتی است.

## کدام فایل را دانلود کنم؟

اگر یک executable بدون نیاز به Python می‌خواهید standalone مناسب است. برای محیط‌های Python از pipx/wheel و برای یکپارچگی سیستمی Linux از DEB/RPM استفاده کنید.

## باگ را چگونه گزارش کنم؟

`bashref --format json doctor` را اجرا کنید، اطلاعات حساس را حذف کنید و همراه فرمان دقیق، روش نصب، سیستم‌عامل، نتیجه مورد انتظار و نتیجه واقعی در GitHub Issue قرار دهید.
