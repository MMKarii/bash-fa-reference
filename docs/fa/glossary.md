# واژه‌نامه دوزبانه

| فارسی | English | توضیح |
|---|---|---|
| پوسته | Shell | مفسر فرمان و محیط تعاملی/اسکریپتی |
| پردازه | Process | نمونه در حال اجرای برنامه |
| جریان ورودی | stdin | ورودی استاندارد |
| جریان خروجی | stdout | خروجی استاندارد |
| جریان خطا | stderr | خروجی خطای استاندارد |
| خط لوله | Pipeline | اتصال خروجی یک فرمان به ورودی فرمان بعد |
| هدایت | Redirection | تغییر مقصد یا منبع جریان‌های I/O |
| متغیر محیطی | Environment variable | داده نام‌دار منتقل‌شونده در محیط پردازه |
| گسترش | Expansion | تبدیل‌های Shell پیش از اجرای فرمان |
| الگوی فایل | Globbing | Match نام فایل با wildcard |
| وضعیت خروجی | Exit status | عدد نتیجه اجرای فرمان |
| سیگنال | Signal | پیام کنترلی سیستم‌عامل به پردازه |
| تابع | Function | بلوک قابل استفاده مجدد در اسکریپت |
| نام مستعار | Alias | میان‌بر تعاملی برای متن فرمان |
| وظیفه زمان‌بندی‌شده | Scheduled job | اجرای برنامه در زمان/دوره مشخص |
