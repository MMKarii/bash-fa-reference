# Command summary

Running `bashref` with no arguments or running `bashref usage` prints the concise command summary.

## Common commands

| Command | Purpose |
| --- | --- |
| `bashref search QUERY` | Search all reference records |
| `bashref show TOPIC` | Resolve a record by name, alias, or canonical ID |
| `bashref builtin NAME` | Show a Bash builtin |
| `bashref syntax NAME` | Show shell syntax |
| `bashref expansion NAME` | Show expansion behavior |
| `bashref option NAME` | Show a shell option |
| `bashref shopt NAME` | Show a shopt option |
| `bashref variable NAME` | Show a Bash variable |
| `bashref list CATEGORY` | List a reference category |
| `bashref doctor` | Diagnose runtime and packaged reference data |
| `bashref docs [TOPIC]` | Print the matching live-documentation URL |
| `bashref man [TOPIC]` | Open an installed manual page when available |
| `bashref completion SHELL` | Generate Bash/Zsh/Fish completion |
