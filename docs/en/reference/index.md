# Bash Reference Guide

The **Reference Guide** is the lookup-oriented part of Bashref. It is generated from the same canonical records used by the CLI and man pages, so command syntax, summaries, and source links stay aligned.

Use it when you need a precise answer about a builtin, shell option, expansion, variable, syntax form, or core Bash concept.

- [Complete generated index](generated/)
- CLI lookup: `bashref builtin printf`
- CLI search: `bashref search quoting`
- Machine-readable output: `bashref --format json builtin read`

For step-by-step learning and operational workflows, use the [Professional Guide](../book/).
