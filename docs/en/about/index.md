# About Bashref

Bashref is a bilingual Persian/English Bash reference project built around three first-class layers:

1. **Bashref CLI** for offline terminal lookup and search.
2. **Reference Guide** for precise Bash builtins, syntax, expansions, options, variables, and concepts.
3. **Professional Guide** for structured learning, administration, automation, DevOps, debugging, and defensive scripting.

The project uses the GNU Bash Reference Manual as the primary authority for Bash-specific semantics. Bashref does not replace the GNU manual and does not execute documentation examples.
