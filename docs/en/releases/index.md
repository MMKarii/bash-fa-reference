# Releases

## Bashref 2.1.0

Bashref 2.1.0 expands the structured bilingual reference to 214 records and adds broad shell-option, shopt, Bash-variable, and compound-command syntax coverage.

It also adds:

- `bashref stats` for corpus coverage
- `bashref doctor` for offline runtime diagnostics
- dedicated `INSTALL.md`, `HACKING.md`, `AUTHORS.md`, and `NEWS.md`
- immutable tag-built documentation snapshots
- version-aware release verification

## Bashref 2.0.0

The first integrated software release introduced the installable CLI, 97-record bilingual corpus, generated Reference Guide and man pages, completions, wheel/sdist, Debian/RPM packages, Homebrew formula, portable archives, checksums, and the 14-chapter Professional Guide.

The v1.0.0 documentation release remains available as an immutable historical snapshot.

See the [project releases](https://github.com/MMKarii/bash-fa-reference/releases).
