# Bilingual Glossary

| فارسی | English | Meaning |
|---|---|---|
| پوسته | Shell | command interpreter and scripting environment |
| پردازه | Process | running instance of a program |
| جریان ورودی | stdin | standard input |
| جریان خروجی | stdout | standard output |
| جریان خطا | stderr | standard error |
| خط لوله | Pipeline | connection from one command's output to the next input |
| هدایت | Redirection | changing the source/destination of I/O |
| متغیر محیطی | Environment variable | named value inherited through process environments |
| گسترش | Expansion | shell transformations before command execution |
| الگوی فایل | Globbing | filename pattern expansion |
| وضعیت خروجی | Exit status | numeric command result |
| سیگنال | Signal | OS control notification sent to a process |
| تابع | Function | reusable shell code block |
| نام مستعار | Alias | interactive textual shortcut |
| وظیفه زمان‌بندی‌شده | Scheduled job | task run at a defined time or interval |
