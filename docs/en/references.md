# References

## Authoritative technical references

- [GNU Bash Reference Manual](https://www.gnu.org/software/bash/manual/bash.html) — primary reference for Bash syntax and semantics.
- [GNU Bash project](https://www.gnu.org/software/bash/) — official project page.
- [ShellCheck](https://github.com/koalaman/shellcheck) — static analysis for shell scripts.
- [ShellCheck website](https://www.shellcheck.net/) — online analyzer.
- [POSIX Shell Command Language](https://pubs.opengroup.org/onlinepubs/9799919799/utilities/V3_chap02.html) — portability reference for standard shell language.

## Project source set

This project consolidates the Word documents supplied by the repository owner, including the full Bash reference, the 2025 academic revision, the corrected revision, and security-focused material. Repeated placeholder/filler sections are deliberately excluded.

When a source example conflicts with Bash semantics, the GNU Bash Reference Manual takes precedence.
