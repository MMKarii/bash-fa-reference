# Changelog

All notable documentation and tooling changes are recorded here.

## [2.0.0] - Unreleased

### Added
- installable `bashref` Python package and console command
- offline Persian/English reference loader with deterministic packaged data
- structured JSON/text output and stable CLI exit codes
- offline search, typo suggestions, language preferences, docs/man routing, and Bash/Zsh/Fish completion generation
- CI build and installed-wheel smoke testing

- 14 mirrored chapters plus learning path, cheat sheet, glossary, references, and disclaimer
- GNU Bash 5.3 cross-checks for shell semantics
- ShellCheck guidance and portability notes
- Defensive security and safe automation guidance
- RTL/LTR MkDocs builds
- strict CI, local link and anchor validation, external link checking, translation-drift checks, and built-site accessibility/metadata QA
- root language selector, `latest` aliases, stable `v1.0` snapshot, social preview asset, and `gh-pages` deployment
- issue templates, PR template, CODEOWNERS, security policy, contribution guide, and repository metadata guidance
